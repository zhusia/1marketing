# Bundled fonts

These web fonts are bundled with the app and inlined (as base64 `data:` URIs) into the
offscreen design-render documents so Design Studio renders distinctive, deterministic
typography fully offline. All five families are licensed under the **SIL Open Font License,
Version 1.1** (`LICENSE-OFL.txt`). Each `.woff2` is the Latin-subset variable font from Google
Fonts (except Archivo Black, a single-weight static face).

| File | Family | Role | Copyright / source |
| --- | --- | --- | --- |
| `Inter.woff2` | Inter | Body / UI | © The Inter Project Authors — https://github.com/rsms/inter |
| `SpaceGrotesk.woff2` | Space Grotesk | Geometric display | © Florian Karsten — https://github.com/floriankarsten/space-grotesk |
| `ArchivoBlack.woff2` | Archivo Black | Heavy display | © Omnibus-Type — https://github.com/Omnibus-Type/Archivo |
| `Fraunces.woff2` | Fraunces | Editorial serif display | © The Fraunces Project Authors — https://github.com/undercasetype/Fraunces |
| `JetBrainsMono.woff2` | JetBrains Mono | Mono / labels | © JetBrains s.r.o. — https://github.com/JetBrains/JetBrainsMono |

The OFL permits bundling and embedding in software. `LICENSE-OFL.txt` is the OFL 1.1 text
(carrying the Inter copyright header); the same license version covers every family above.
